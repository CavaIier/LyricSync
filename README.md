# 🎵 LyricSync — Juicey Synced Lyrics & LRC Archive

Trying to make a place where you can find synced lyrics for juice songs

---

## ✨ Features

- 🔍 **Search**: Fast, client-side filtering as you type by song title or lyrics, features, or era. Press `/` anywhere to focus search.
- 📋 **Copy**:
  - **Copy Clean Lyrics**: Copies plain text lyrics without timestamps or tags.
  - **Copy .LRC**: Copies properly formatted, synchronized LRC lines with timestamps.
  - Quick copy buttons directly on song cards without opening the modal!
- 📥 **Downloads**:
  - **Download .LRC**: Saves a standard `.lrc` file universally compatible with Spotify, Walkman, Poweramp, Musicolet, Foobar2000, etc.
  - **Download .TXT**: Plain text lyrics download.
- 🎤 **Interactive Sync Viewer**:
  - Click any timestamp to jump to that moment in the track.
  - **Live Auto-Scroll Simulation**: Simulated playback engine that highlights the current line and scrolls lyrics in real time.
  - **Load Audio File**: Select or drag & drop your own audio track to listen while lyrics scroll the lyrics live to check if its properly synced.
